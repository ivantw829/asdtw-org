ACCESSIBILITY

無障礙與聯絡

我們希望每個人都能順利閱讀這個網站。這一頁說明已做的措施、尚未做到的地方，以及如何聯絡我們。

閱讀設定怎麼用

每一頁的最上方都有「閱讀設定」，需要啟用 JavaScript。沒有 JavaScript 時，網站會以預設樣式顯示，內容與連結仍可使用，也可以用瀏覽器自己的縮放與高對比功能。

  • 字級：標準、大（125%）、特大（150%）、最大（200%）。
  • 配色：預設配色（奶白紙張底）、深色（暖黑褐底）、高對比（黑底白字與黃色連結）。
  • 設定只儲存在你的瀏覽器裡，下次回來會自動套用。
  • 如果你的系統已經開啟「提高對比」或「深色模式」，網站會自動使用對應的配色。

已做的措施

  • 使用標準 HTML 結構：頁面有標題層級、導覽、主要內容與頁尾等地標，方便螢幕報讀器跳讀。
  • 每一頁最前面有「跳到主要內容」連結。
  • 所有功能都能只用鍵盤操作，焦點框清楚可見。
  • 文字與背景的對比以 7:1 為目標，三種配色都由自動檢查驗證。
  • 內文連結一律有底線；導覽目前所在頁面有形狀與文字加粗標示，不單靠顏色。
  • 會另開新視窗的連結都在文字中註明。
  • 沒有自動播放的影音、閃爍或限時的內容。頁首標誌只在頁面載入時播放約 4 秒的光圈動畫就會停止；切換頁面時，導覽中目前所在頁的黃色膠囊會滑到新位置、頁面內容淡入，約 0.4 秒。系統開啟「減少動態」時不會播放任何動畫。
  • 版面以相對單位製作，放大字級時會自動重新排列。
  • 首頁主視覺、頁尾與行動紀錄頁的標誌圖案都只是裝飾，已對輔助科技隱藏。
  • 按鈕與連結的點擊範圍至少約 44 像素見方。

尚未做到的地方

  • 尚未經過第三方的無障礙稽核。
  • 標題使用襯線字體，但本站不載入外部字體，會依你裝置上有的字體顯示，外觀可能略有不同。
  • 本站沒有照片、影片或音訊。唯一的說明性圖片是「關於與加入須知」頁的身分組示意圖，已附完整的替代文字，圖中的資訊在正文也有同樣內容的文字說明。日後新增圖片、影片或音訊時，會一併補上替代文字、字幕或文字稿。

隱私說明

  • 本站不使用 Cookie，不使用分析或追蹤工具，不載入外部字體與外部腳本。
  • 閱讀設定只存在你瀏覽器的本機儲存空間，不會送出。
  • 本站不刊登照片，也不列出成員名單。
  • 網站由 GitHub Pages 代管，GitHub 可能依其政策記錄連線資料。
  • 點選 Discord 邀請連結後，適用 Discord 的隱私政策。
