ACCESSIBILITY

アクセシビリティ・連絡先

すべての人が快適にこのサイトを読めることを目指しています。ここでは実施済みの対策、今後の課題、およびお問い合わせ方法をご案内します。

閲覧設定の使い方

各ページの最上部に「閲覧設定」があり、利用には JavaScript が必要です。JavaScript が無効な場合でも、言語切り替えを含めサイトは標準スタイルで問題なく閲覧・操作でき、ブラウザ標準の拡大表示やハイコントラスト機能も利用できます。

  • 文字サイズ：標準、大（125%）、特大（150%）、最大（200%）。
  • 配色：標準配色（生成りの紙のような背景）、ダーク（温かみのある暗褐色）、ハイコントラスト（黒背景に白文字と黄色のリンク）。
  • 設定はお使いのブラウザのローカルストレージのみに保存され、次回訪問時に自動で適用されます。
  • OS 側で「コントラストを上げる」または「ダークモード」が有効になっている場合、対応する配色が自動的に適用されます。

実施済みの対策

  • 標準的な HTML 構造を採用し、見出し階層・ナビゲーション・メインコンテンツ・フッターのランドマークを整備してスクリーンリーダーで移動しやすくしています。
  • すべてのページの先頭に「メインコンテンツへ移動」リンクを設置しています。
  • すべての機能をキーボードのみで操作でき、フォーカス枠が明確に表示されます。
  • 文字と背景のコントラスト比は7:1（WCAG AAA）を目標とし、3種類の配色すべてを自動チェックで検証しています。
  • 本文中のリンクにはすべて下線を付け、ナビゲーションの現在ページは色だけでなく形状と太字で示しています。
  • 新しいタブで開くリンクには、すべてリンクテキスト内にその旨を明記しています。
  • 自動再生される音声・動画、点滅、時間制限のあるコンテンツはありません。ヘッダーのロゴはページの読み込み時に約4秒間だけ波紋のアニメーションを再生して止まります。ページを切り替えると、ナビゲーションで現在のページを示す黄色の背景が新しい位置へ移動し、本文がフェードインします（約0.4秒）。OS で「視差効果を減らす／アニメーションを減らす」が有効な場合はすべてのアニメーションが停止します。
  • レイアウトには相対単位を使用し、文字サイズを拡大しても自然に再配置されます。
  • ホームのメインビジュアルやフッター・行動記録ページのロゴ装飾は支援技術から隠しています。
  • ボタン、ナビゲーション、言語切り替え、閲覧設定のタップ領域は少なくとも約44ピクセル四方を確保しています（本文内リンクや記事のカテゴリタグはこれより小さい場合があります）。
  • 記事内の横幅の広い表はキーボードでフォーカスして横スクロールできます。

今後の課題・既知の制約

  • 第三者機関によるアクセシビリティ監査はまだ受けていません。
  • 見出しには明朝体・セリフ体を使用していますが、外部フォントを読み込まないため、お使いの端末にインストールされているフォントによって見え方が多少異なります。
  • 本サイトに写真・動画・音声はありません。説明用の図版は「概要・参加案内」のロール選択模式図および一部記事内の模式図のみで、いずれも代替テキストとキャプションを添え、図中の情報を本文でも文字で説明しています。今後新たに画像・動画・音声を追加する際は、代替テキスト・字幕・文字起こしを併せて提供します。
